# Ranking

Order every list by, in this priority:
1. **Idea fit** — how directly it answers the topic or question asked.
2. **Book fit** — fit with the user's library, notes, taste and reading level (check Book Hub).
3. **Read-worthiness** — timeless verdict, density (no padding), evidence.

**Price never affects rank.** It only affects the buy decision.

Never pad a list. Return fewer than asked, or none with a reason. Flag a strong extra pick ("worth adding as a 6th") when there is one.
Textbooks are excluded unless nothing else fits; tag them "Textbook" when included.
