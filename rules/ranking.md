# Ranking

Order every list by, in this priority:
1. **Match:** how directly it answers the question asked (Direct · Strong · Partial).
2. **Quality gate:** books that fail a Quality gate are not recommended.
3. **Quality score** breaks ties within the same Match.

- **Fit is shown, never reorders.** The reader decides with it.
- **The library never changes rank or hides a book.** Books the reader has finished keep their place, labelled ✓, and can get "Reread chapters…" as the For this question line. Only archived books are dropped.
- **Price never affects rank.** It only affects how to get the book.
- Never pad a list. Return fewer than asked, or none with a reason. Flag a strong extra pick ("worth adding as a 6th") when there is one.
- Textbooks are excluded unless nothing else fits; tag them "Textbook" when included.
- No question (check-in): order by Quality × Fit.
