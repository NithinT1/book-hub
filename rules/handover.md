# Hand-over

When to move to another step automatically, and when to ask first. Automatic when it's quick and obvious; ask first when it costs the reader time or a lot of usage.

- Recommendations get a URL or book names → run book details. Picks get full cards.
- Book details get a topic or "books like X" → run recommendations.
- Unclear whether fiction or non-fiction, or fiction with no mood given → ask 1–2 quick questions first.
- A URL with more than 5 new books → ask before researching them all.
- Verdict Idea only → offer a long summary as a link line ("Long summary: /book-summary …"); don't write it unasked.
- Anything that takes the reader more than a few minutes (Book Quiz, a long interview) → offer it as a link line with the time it takes; never start it unasked. Never offer a quiz at a bookstore.
- End answers with Book Hub links, never with "shall I…?" questions.
