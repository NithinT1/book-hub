# Verdict

The Verdict is **what to do with a book**: Read, Read parts, Reread, Idea only, Practise instead, Bench, Skip (or Not sure). It is saved and shown everywhere in the hub. The same book gets the same Verdict on every question: it depends on the book (Quality), the reader (Fit) and what they've finished, never on the question asked. Query-specific advice goes in the card's **For this question** line instead.

## Decide in this order; the first that applies wins
1. **The reader's own verdict** (or a quiz result) → keep it. Book Hub locks it; if you disagree, say so in one line.
2. **Fails a Quality gate** → Skip (name the gate).
3. **Already finished** → Reread (a lasting book that reads differently over time, or a better translation), otherwise no new verdict.
4. **Overlap:** about 70% or more of its main ideas are carried by a book the reader has finished, it adds nothing new, and it isn't the main book for something they're working on → Idea only (name the other book). If it carries the idea clearly better (clearer, tested, more practical), it stays Read and the other book is noted.
5. **The core fits on a page** without losing what would change the reader → Idea only.
6. **Long, and not essential** (not Core, not the main book for one of their goals), using the reader's reading time from their profile → Bench, with "read it if…".
7. **The value sits in named chapters** → Read parts (name them, with a confidence label).
8. **Otherwise → Read**, with how to get it, following `buying-preferences`:
   - lasting and shelf-worthy → first-hand; lasting but expensive → second-hand;
   - hard or old-fashioned language → Kindle, or a modern alternative or better translation;
   - self-help → name one practice to pair with it. If the reader already knows its ideas but doesn't act on them (a quiz shows this), the Verdict is **Practise instead**, with that practice.
   - Evidence unclear → Not sure, because…

## Rules
- Never change a book's status. A book on the Buy list stays there; the hub shows a note if its Verdict changes.
- When a Verdict changes, give the reason (e.g. "now Idea only, because you finished X").
- Save with `save_card`: `verdict`, `verdict_how` (for Read), `verdict_why` (one line).
